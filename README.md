# Adventureworks-product-categories-analysis
Project Description

This project performs Exploratory Data Analysis (EDA) on the AdventureWorks Product Categories dataset. The dataset consists of product category information from the popular Microsoft AdventureWorks sample database.
 Includes data cleaning, filtering, grouping, and visualization using Python and Pandas. Ideal for learning basic data analysis techniques and understanding product category trends.
 
 The repository demonstrates:

Data Loading & Inspection – Importing CSV data into Pandas, checking column types, and basic statistics.

Data Cleaning – Ensuring data consistency and handling missing values (if any).

Data Exploration – Summarizing product categories, counting category frequencies, and preparing the data for further analysis.

Visualization – Simple bar charts and tables to better understand the distribution of product categories.

This project is ideal for beginners learning data analysis with Python and serves as a starting point for deeper analysis, such as joining with product subcategories or sales data for richer business insights.
